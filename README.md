# 考试倒计时桌面小工具

一个简洁、实用的桌面倒计时小工具，帮助学生及家长精准掌握距离中考/高考的剩余时间。

## 功能特点

- **多考试类型支持**：同时支持中考、高考和自定义倒计时，可随时切换
- **全国各省市考试日期**：内置2025年全国各省市中考和高考日期数据
- **多科目倒计时**：支持文化课、地理生物、英语听说等不同科目的倒计时
- **自定义模式**：支持用户输入自定义文本，使用{time}标记指定数字位置
- **高精度显示**：支持0-8位小数精度设置，精确显示剩余天数
- **自由定位**：可将窗口固定在屏幕四个角落任意位置
- **双显示模式**：
  - 水印模式：半透明显示，不影响桌面操作
  - 高辨识度模式：清晰可见，适合快速查看
- **鼠标穿透**：即使窗口显示在最前，也不会影响下方内容的操作
- **托盘菜单**：支持系统托盘操作，便捷控制各项功能
- **单例模式**：防止重复运行多个程序实例
- **版本号系统**：支持自动更新考试日期数据

## 安装方法

### 方法一：直接运行Python脚本

1. 确保已安装Python 3.8或更高版本
2. 安装所需库：`pip install PySide6`
3. 下载`main.py`文件
4. 运行脚本：`python main.py`

### 方法二：使用打包版本

1. 从Releases页面下载最新版本的可执行文件
2. 解压缩后直接运行`考试倒计时.exe`

## 使用说明

### 首次使用

1. 首次运行时，会弹出日期选择对话框
2. 选择您关注的考试类型（中考/高考/自定义）
3. 选择省份/城市和具体考试科目，或设置自定义文本
4. 点击"确定"按钮完成设置

### 基本操作

- **查看倒计时**：运行程序后，倒计时将显示在屏幕选定位置
- **隐藏/显示窗口**：单击系统托盘图标
- **访问设置**：右键点击系统托盘图标，打开菜单
- **重复运行提示**：程序已在运行时，再次启动会显示提示对话框

### 托盘菜单选项

- **窗口位置**：选择倒计时窗口在屏幕上的位置
- **显示模式**：选择水印样式或高辨识度模式
- **设置精度**：调整小数位数精度（0-8位小数）
- **暂停/恢复更新**：暂时冻结或恢复倒计时更新
- **切换模式**：在中考、高考和自定义模式之间切换
- **修改日期设置**：重新设置考试日期或自定义文本
- **恢复出厂设置**：将所有设置恢复到默认状态
- **退出**：完全退出程序

## 配置文件

程序会自动保存您的设置到用户文件夹中的`.countdown/countdown_config.json`文件中，包括：

- 考试类型和科目
- 目标日期
- 显示位置和模式
- 精度设置
- 自定义文本模板
- 版本号信息

重新启动程序时，会自动加载上次的设置。如果检测到更高版本号，会更新考试日期数据。

## 注意事项

- 考试日期数据来源于网络整理，仅供参考，请以当地教育部门通知为准
- 配置文件会自动保存在用户目录中，以便支持编译版本使用
- 可以手动修改配置文件中的考试日期，程序会尊重您的修改
